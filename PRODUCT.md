# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
delegated: Python FastAPI backend and React/Vite frontend for a reproducible local research console.

## Users
Curious visitors exploring artificial societies, plus researchers and engineers studying emergence, counterfactuals, and intervention effects in complex multi-agent systems.

## Product Purpose
ButterflyLab runs reproducible virtual societies, compares matched counterfactual worlds, and searches for low-cost interventions that change measured outcomes.

## Positioning
The product treats interventions as explicit, costed, replayable experimental variables and reports measured evidence rather than narrative predictions.

## Operating Context
Default Explore Mode offers explicit one-change parallel worlds. The public static demo replays real precomputed rule simulations; local Research Mode retains live experiments, saved seeds, event logs, metric time series and exportable configurations.

## Capabilities and Constraints
The first release must run without model API keys, expose real simulation state, support baseline/intervention comparison and multi-seed search, and distinguish simulated evidence from real-world causal claims.

## Brand Commitments
ButterflyLab — Change One Thing. Watch Two Worlds Diverge. Chinese: 只改变一件事，看看两个世界会走向哪里。

## Evidence on Hand
Synthetic deterministic simulation data generated by the engine. No real-world social data or predictive claims.

## Product Principles
Reproducibility before spectacle. Every visual is backed by state. Interventions are explicit and costed. Results include uncertainty and limitations. The default demo works offline.
