# Dependencies, assets and experimental data

Original project source is offered under MIT. Dependency licenses remain their
respective owners' licenses; the project license does not relicense them.
Pinned dependency versions are in the Python and npm locks.

Core third-party libraries: React, Vite, Recharts, Lucide (MIT/ISC as distributed),
FastAPI/Pydantic/HTTPX/Starlette (MIT/BSD as distributed), NetworkX and NumPy
(BSD). Check installed distribution/package LICENSE files before redistribution
of binary bundles. CI/browser tooling and FFmpeg are development tools and are
not shipped as product source. No external stock imagery is included.
The project mark reuses the locally authored network-signal identity; product
screenshots show actual Rule/Mock runs. They are not scientific evidence of LLM
performance. Sanitized fixture contains one authentic connectivity action.

All worlds are synthetic; no real social/person data is imported. Local database
and raw outputs are excluded from public distribution. Review names, model
reasons, logs and any provider metadata before deliberately publishing additional
archives. Model outputs may be subject to provider terms; this work does not
claim ownership or permission beyond the operator's authorized API use. Current
account-specific redistribution terms have not been legally audited.

Installed metadata inspected locally: Certifi MPL-2.0; OpenTelemetry API Apache-2.0;
Packaging Apache-2.0 OR BSD-2-Clause; typing_extensions PSF-2.0; NumPy includes
BSD/0BSD/MIT/Zlib/CC0 notices. React/Vite/Recharts MIT, Lucide ISC. Retain these
notices when redistributing their code or bundled binaries; the source release
contains locks rather than vendored packages. This is a metadata inventory, not
an exhaustive legal review.
