# LLM pilot / Phase 2D

## Research question and pre-registration

Does adding three real LLM decision makers change final information coverage
in the same synthetic society? Information coverage is the sole primary endpoint;
cooperation, trust and resources are explanatory measurements, not a second
search for favorable results. The existing cascade preset is retained except its
BA topology is explicitly overridden with the requested small-world network.

Protocol `hybrid-pilot-1.0.0`: 50 agents, eight rounds, seeds **42,43,44,45,46**,
Watts-Strogatz degree 4, rewiring 0.15, transmission 0.25, initial trust 0.6,
trust speed 0.03, incentive 0.3. All mechanisms remain enabled. Complete configuration
is generated by `backend.pilot.configuration` and included in every saved result.
Select the three highest **initial unweighted degrees**, ties by numeric Agent ID,
separately per seed before simulation. A and B share identical initial states,
edges, resources, opinions and addressable random streams. Only selected B agents
use the alternative decision strategy; the other 47 remain rules.

Actions: strict booleans `cooperate` and `propagate`, neighbor ID or null `target`,
reason at most 160 characters. Null targets all neighbors. The deterministic
engine applies transfers, diffusion and trust changes. Invalid actions are rejected
and explicitly recorded as rule fallbacks. Context is local role/resources/trust,
neighbors, opinion and at most two recent events. It cannot edit world state.

## Real connectivity: completed, bulk research: blocked

TokenHub route `openai/gpt-5.6-luna` returned actual model **gpt-5.6-luna**.
Exactly **one** authenticated Chat Completions request succeeded with a valid JSON
action: cooperate, propagate, null target. Usage: **4498 input + 91 output = 4589
tokens**, zero reported reasoning tokens; latency **3.175 seconds**; zero failures,
zero fallback in that connectivity request. No later paid requests were made.

The authenticated model-list/public quote is USD 1/M input and USD 6/M output.
Quote-only arithmetic is USD **0.005044**; it is **not** a confirmed account bill.
Account-effective billing could not be authenticated/verified. Actual CNY expense
is unknown; the ledger retains **CNY 1 as a conservative reservation**, not a paid
invoice. No verified CNY price or exchange rate is asserted. Software reserves
below CNY 10 and caps requests at 125; it cannot enforce provider-side billing.
Reported input exceeded the 1500-token target despite the compact prompt. Its
cause has not been established. Both gates block further paid calls.

Therefore the real one-seed 3-agent pre-experiment and real five-seed comparison
are **not completed**. There is no real LLM paired-effect estimate, no independent
real seed evidence and no conclusion that LLMs improve or impair propagation.

the interval is not a general significance claim. This result describes Mock only.

## Authentic action diagnostic and replay

`examples/connectivity-action.json` preserves the sanitized authentic action and
usage. The free verification applies it once to Agent 0, round 1 in an offline
50-agent engine diagnostic, followed by **seven explicit rule fallbacks**.
The original connectivity context differs from this diagnostic simulation.
It verifies integration and identical snapshots, events, decisions, transmission
paths and metrics on recorded replay; it is **not** a three-LLM-Agent live run.
The fixture is a historical record and never pretends to be a live request.

Saved Rule/Mock pilots can be opened in LLM Society and replayed with
`POST /api/llm/pilots/{experiment_id}/replay`. Light JSON contains configuration,
seeds, final metrics and summaries; the full archive contains decision tapes and
trajectories. Engine remains `social-1.0.0`; dependency/runtime fingerprints are
recorded. Fresh live LLM outputs cannot promise exact equality; stored tapes can.

## English research summary

The real model route and structured action were verified in one connectivity
request. Account-effective pricing was unavailable and reported input exceeded
the target, so the real five-seed research pilot was stopped before execution.
The available evidence cannot answer whether three real LLM agents change
propagation. Free paired controls and an authentic historical-action diagnostic
verify simulation integration and deterministic recorded replay, not LLM efficacy.

Next step requires resolving account price and input overhead before any new
explicitly initiated live run. Preserve the registered seeds and primary metric;
do not tune the scenario in response to Mock results.
